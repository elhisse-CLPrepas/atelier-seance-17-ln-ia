# Analyse et révision de S17

## Source retenue

Le mini-site fourni présente déjà les fondations du Web : trois responsabilités (HTML, CSS, JavaScript), un bouton afficher/masquer, une arborescence, le navigateur, la console et les états local/public. Ce contenu correspond à l’objectif « COMPRENDRE ». Il constitue le support commun de S17.

Le dossier Challenge contient l’accueil, le suivi, les prompts, les productions et le portfolio. Il sert de point d’entrée au travail personnel. Les fichiers de préparation des séances suivantes sont conservés.

## Dispositions appliquées

- Copie de travail du mini-site dans `04-WEB/mini-site-demonstration/`.
- Accès explicites aux fichiers, au dossier, au carnet et au retour en haut.
- Menu adaptable, repères de focus et décalage des sections pour préserver les titres lors des sauts de navigation.
- Carnet autonome avec saisie, conservation navigateur, sauvegarde/reprise JSON, export Markdown et impression.
- Questions sur HTML, CSS, JavaScript, navigateur, console, clavier, mobile et local/public.
- Présentation de 22 vues et supports associés réécrits autour de ce parcours ; accès au support depuis les vues concernées.
- Plan de page conservé comme préparation facultative de S18.

Les contextes d’exemple ne renseignent jamais des résultats d’essai. Les modèles du portfolio restent à compléter après observation réelle.

## Vérification

La construction Vite et les contrôles de structure passent. Le code du carnet autonome a été exécuté dans un environnement de test : saisie, conservation/reprise, export avec de vrais sauts de ligne, refus d’un import incompatible et maintien d’un statut incomplet.

L’audit inspecte les textes, les PDF, le contenu des archives et du PowerPoint, les chemins HTML et les ancres. Le manifeste SHA256 est régénéré. Le PDF de projection et les deux pages du carnet imprimable ont été rendus et examinés.

La vérification visuelle dans Chrome n’a pas abouti : l’autorisation de contrôle de l’application a expiré. Les essais visuels clavier/mobile dans le navigateur restent à effectuer. Les résultats techniques ne sont pas des observations de participants ni une validation pédagogique. Aucune publication n’a été effectuée.
